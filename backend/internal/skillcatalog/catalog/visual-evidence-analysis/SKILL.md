# 视觉证据分析

## 使命

把真实图片或视频帧的可观察内容转换为结构化、可追溯、可判定陈旧的视觉证据。观察与推断必须分离，不确定性必须保留。

## 输入

- 当前可访问的真实媒体资产 URL、资产 ID、资产版本与来源 revision；
- 分析目的和所需观察维度；
- 已获批准的计费请求上下文，以及指定的视觉模型配置；
- 可选的待核对角色、场景、镜头或首尾帧 artifact revisions。

## 输出

输出新的 `visual_evidence.v1` revision，至少包含：

- 来源资产 ID、资产版本、来源 revision、内容摘要与媒体时间点；
- 可观察的角色身份线索、脸部/头发/体型、服装、配饰和手持物；
- 场景、道具、空间关系、景别、角度、构图和屏幕方向；
- 动作、姿态、视线、首帧/尾帧条件与 OCR 文本；
- 每项观察的置信度、不确定性、冲突和证据区域；
- 模型、渠道、供应商请求 ID、用量事实和分析 run。

## 证据要求

- 只能分析请求时真实存在、可访问且与声明 revision 一致的媒体；
- 每个结论必须能定位到来源帧、时间点或图像区域；
- OCR 结果是观察证据，不自动成为剧本或品牌事实；
- 来源资产版本变化后，旧证据必须标记陈旧，不能继续代表当前资产。

## 禁止假设

- 禁止根据文件名、prompt、节点标题或用户预期声称图片中存在某元素；
- 禁止从外观推断未可见的身份、年龄、族裔、关系、动机或剧情事实；
- 禁止用历史分析、其他候选或相似图片替代当前媒体分析；
- 禁止在模型失败时返回模板观察、默认标签或假置信度。

## Revision 规则

- 每次分析以来源资产版本、模型请求和分析目的形成不可变 revision；
- 重新分析创建新 revision，并保留旧 revision 及其陈旧状态；
- 下游 artifact 必须引用其实际采用的证据 revision，不得只引用资产 URL。

## 失败行为

- 媒体 URL 不可访问、资产版本不匹配或内容无法解码时显式失败；
- 计费审批缺失、模型不可用、请求取消或供应商未返回可解析证据时显式失败；
- 输出缺少来源 revision、请求 ID 或必要不确定性字段时不得发布。

## 方法

1. 校验媒体身份、版本、可访问性与计费批准事实；
2. 按请求维度观察画面，区分直接观察、弱推断和未知；
3. 为观察绑定帧、时间点或区域证据；
4. 记录冲突、不确定性、模型与供应商请求事实；
5. 发布可被角色、分镜、机位、视频和审查流程引用的新证据 revision。
