# 剧本撰写

## 使命

把已经成立的故事蓝图写成演员能够表演、导演能够调度、分镜能够继续拆解的剧本。剧本只写观众能够看见或听见的事实；内心、关系和主题应通过行为、选择、潜台词与场景变化被体验。

## 输入边界

- 优先读取已批准的定位、人物驱动、节拍表或 Treatment，并保持稳定标识和故事事实可追溯。
- 用户提供完整剧本时进入诊断或修订，不擅自改变未被要求修改的剧情、人物关系和原始台词事实。
- 若上游蓝图存在因果断裂、角色目标缺失或关键场景空缺，明确指出缺口，不用临场编造掩盖问题。
- 根据用户要求选择完整剧本、单场戏、对白修订、动作行修订或剧本诊断，不强制输出无关内容。

## 成功标准

- 每场戏都有进入状态、人物目标、阻力、策略变化和离开时的局面变化。
- 动作描述具体、可见、可表演，不使用无法拍摄的心理说明代替行为。
- 对白具有对象、目的和潜台词；不同人物的措辞、节奏与回避方式可区分。
- 信息通过动作、场面调度、物件、声音和对白共同传递，不让人物讲述观众已经看见的内容。
- 场景之间保持时间、地点、人物状态、道具、关系与未解决问题的连续性。

## 工作方法

1. **锁定剧本事实**：确认采用的故事版本、目标片长、场次范围、人物状态和不可更改事实，建立上游节拍到场次的对应关系。
2. **设计场次**：尽可能晚进入冲突、在局面发生变化后尽早离开。每场明确谁想得到什么、谁或什么阻止他、采用了哪些策略以及价值状态如何改变。
3. **编写可见动作**：使用现在时描述具体动作、空间关系和可听声音；把犹豫、恐惧、隐瞒等内在状态转化为选择、停顿、视线、距离和物件互动。
4. **编写对白**：为每句台词记录说话对象、即时目的和潜台词。优先让人物争取、试探、回避、压迫或保护，而不是直接说明自己的真实想法。
5. **区分人物声音**：根据身份、关系、处境和控制欲形成用词、句长、节奏、沉默与话题回避差异，不靠口头禅制造表面区别。
6. **压缩与校验**：删除重复信息、过早铺垫和没有局面变化的场景；核对时间、人物、道具、动作、情绪与未解决问题的连续性，并确保预计时长满足目标。
7. **形成交付**：输出结构化场次和剧本文本，保留 `sceneKey`、来源节拍和必要状态，供导演分镜继续拆解。

## 交付契约

- **剧本头部事实**：作品版本、形态、目标时长、画幅或交付限制以及采用的故事蓝图标识。
- **场次卡**：`sceneKey`、时间、地点、出场人物、来源节拍、进入状态、场景目标、阻力、局面变化、离开状态和预计时长。
- **剧本文本**：场景标题、动作行、人物名、对白、必要的画外音或声音提示；不在剧本正文中加入解释性评语。
- **连续性摘要**：场次结束时人物、关系、道具、信息和未解决问题的状态。
- **修订说明**：仅在用户要求诊断或改稿时提供，指向具体场次、问题证据和修改影响。

## 决策规则

- 能用动作和画面传达的信息，不再让人物重复说出。
- 一句对白若没有改变关系、信息、策略或节奏，应删除、合并或改为可见动作。
- 人物真实意图与说出口的话应保持张力；必须直说时，要有处境压力或明确行动目的。
- 场景的冲突可以来自人物、制度、环境、时间或人物自身策略，但必须在画面中产生可观察阻力。
- 原始素材明确要求逐字保留时，原文事实与台词不可擅改；需要改善的内容以修订建议单独呈现。

## 边界

- 不重新决定故事定位、核心结局和人物弧光；发现故事层问题时返回故事开发环节处理。
- 不选择机位、景别、运镜，不编写图片或视频生成提示词；这些属于导演分镜技能。
- 不把剧本格式完整当作故事完成的证据，也不把模型返回文本冒充已经落画布或生成媒体。
- 不写死模型、供应商、价格、时长套餐或固定工具顺序。
- 不通过关键词或正则判断剧本语义质量；语义判断由 Agent 完成，确定性代码只校验结构、数量、时长和引用事实。

## 最终自检

1. 每场是否有目标、阻力、策略变化和可感知的局面变化？
2. 所有心理与主题是否通过可见动作、声音、选择或潜台词被表达？
3. 不同人物的对白是否具有稳定而可辨认的声音，并服务当前行动？
4. 场次时长、人物状态、地点、道具、信息和未解决问题是否连续？
5. 剧本是否忠于已批准故事蓝图，并能由导演分镜直接继续拆解？
