# 后台布局个性化设计

## 目标

在不替换现有后台路由、权限和导航数据的前提下，引入与 Ant Design Pro `SettingDrawer` 同类的后台外观配置能力。管理员可即时调整后台明暗主题、菜单主题、品牌色、侧栏宽度和内容宽度；配置只影响当前浏览器中的管理后台，不影响创作端、其他管理员、后端数据或云端升级流程。

本阶段继续使用侧边菜单，不实现顶部菜单和混合菜单。

## 设计依据

Ant Design Pro 将 `navTheme`、`colorPrimary`、`contentWidth`、`siderWidth`、`fixedHeader` 和折叠状态集中为布局设置，再由布局外壳与设置抽屉共同消费。本项目复用该配置模型的思想，但不引入完整 `@ant-design/pro-components`，避免替换现有路由、权限和菜单体系。

## 配置契约

新增单一的 `AdminLayoutSettings`：

```ts
type AdminThemeName = "light" | "dark";
type AdminMenuTheme = "follow" | "light" | "dark";
type AdminSiderWidth = 208 | 236 | 272;
type AdminContentWidth = "fixed" | "fluid";

type AdminLayoutSettings = {
    theme: AdminThemeName;
    menuTheme: AdminMenuTheme;
    colorPrimary: string;
    siderWidth: AdminSiderWidth;
    contentWidth: AdminContentWidth;
    fixedHeader: boolean;
};
```

默认值：

- 后台主题：浅色。
- 菜单主题：跟随后台主题。
- 品牌色：`#2979C9`，与当前后台品牌色一致。
- 侧栏宽度：236px。
- 内容宽度：流式。
- 固定顶部栏：开启。

本地存储使用一个版本化键 `hmaigc:admin-layout-settings:v1`。读取时对每个字段进行闭集校验；整个对象损坏或字段不合法时显式使用设计默认值，不兼容旧的平行配置键。创作端主题键保持不变。

## 设置抽屉

桌面后台顶栏右侧增加“界面设置”图标按钮，打开 360px 右侧抽屉。移动端顶栏保留同一入口，抽屉宽度不超过视口。

抽屉按职责分为四组：

1. 整体主题：浅色、深色。
2. 菜单主题：跟随页面、浅色、深色。
3. 品牌与密度：预设品牌色、受控自定义颜色、侧栏宽度。
4. 页面布局：固定内容、流式内容、固定顶部栏。

底部提供“恢复默认设置”。设置点击后立即预览并持久化，不增加无意义的保存按钮。恢复默认值必须一次性恢复全部字段，并提供明确反馈。

自定义颜色只接受完整的 `#RRGGBB`；非法值停留在输入框并展示字段错误，不修改当前生效主题。预设色使用克制的蓝、青、紫色系，不开放会破坏成功、警告、危险语义的红、橙、绿色作为品牌主色。

## 布局行为

### 侧栏

- 仅桌面宽度 `>=1280px` 使用 208、236、272px 配置。
- 折叠态统一为 64px，不受展开宽度影响。
- `1280px` 以下继续使用 56px 顶栏和 320px 导航抽屉，避免自定义宽度挤压业务内容。
- 菜单文字、分组标题、选中态和图标只消费主题变量，不维护平行颜色分支。

### 内容宽度

- `fixed`：页面框架有效宽度最大 1120px，居中显示。
- `fluid`：页面框架使用可用空间，但最大不超过全局规范规定的 1304px。
- 两种模式均保留桌面 32px、移动端 16px 页面内边距。
- 宽表格仍只在自身内容区横向滚动，不把横向滚动转移到页面根节点。

这样既能产生可见的宽度差异，又不突破 `Design.md` 对后台最大宽度的约束。

### 顶栏

- `fixedHeader=true` 时顶栏固定在后台内容区域顶部，页面内容独立滚动。
- `fixedHeader=false` 时顶栏随页面内容滚动，但移动端导航入口必须始终可访问。
- 设置抽屉和所有 Ant Design 弹层继续挂在 `.admin-theme-root`，确保独立主题不会被创作端污染。

## 模块边界

1. `admin-layout-settings`：纯类型、默认值、解析、持久化和上下文，不负责渲染。
2. `admin-layout-settings-drawer`：只渲染和编辑设置，不拥有后台路由或导航数据。
3. `admin-shell`：消费设置，驱动侧栏、顶栏和页面框架 CSS 变量。
4. `admin-theme`：从统一设置读取后台主题和品牌色，继续负责 Ant Design `ConfigProvider` 与弹层容器。

禁止同时保留旧的独立后台主题状态和新布局设置状态；实施时进行硬切换，保证一个事实源。

## 状态与失败

- 本地设置读取失败不阻断后台进入，明确恢复为设计默认值。
- 非法自定义颜色只阻止该字段应用，不影响已经生效的配置。
- 设置抽屉不请求后端，不伪造同步状态。
- 配置写入本地存储失败时展示明确错误，并保留本次内存预览；不得显示“已保存”。

## 可访问性与响应式

- 设置入口、主题卡片、颜色选项和宽度选项必须支持键盘操作与可见焦点。
- 图标按钮提供准确 `aria-label`。
- 390px 下主要控件高度不低于 44px，抽屉宽度不超过视口减 24px。
- 主题切换保持相同信息层级和对比度，不通过降低透明度隐藏文字。
- 动效遵循 `prefers-reduced-motion`。

## 验收标准

自动化测试覆盖：

- 默认值、合法持久化和损坏数据恢复。
- 创作端主题不被修改。
- 菜单跟随、强制浅色、强制深色三种组合。
- 品牌色实时进入 Ant Design token 与后台语义变量。
- 208、236、272px 展开宽度与 64px 折叠宽度。
- fixed/fluid 内容宽度。
- 恢复默认设置。
- 自定义颜色字段错误与存储写入失败。

真实浏览器验收覆盖 1440×900、1024×768、390×844：

- 明暗主题和独立菜单主题。
- 侧栏宽度、折叠状态、内容宽度和固定顶栏。
- 设置抽屉、下拉弹层的主题归属。
- 页面根节点无横向溢出。
- 刷新后配置保持。
- 浏览器控制台无错误。

## 变更预算与暂缓项

- 生产职责：设置状态、设置抽屉、后台外壳消费，共 3 项。
- 预计生产文件：不超过 8 个。
- 预计净新增生产代码：400–600 行。
- 昂贵门禁只在稳定里程碑执行：全量 Web 测试、生产构建、Docker 镜像、真实浏览器矩阵。
- 暂缓顶部菜单、混合菜单、云端同步、管理员级共享配置、色弱模式和用户自定义任意圆角/字号，避免把后台设置演变成无限主题编辑器。

## 云端升级影响

本功能是前端本地布局设置：不修改数据库、后端 API、支付、模型调用、部署脚本、运维控制器或版本检查协议。发布时只需按现有流程构建新的 Web 镜像，不改变云端后台点击升级的机制。
