# 会员商城页面关闭入口设计

## 目标

为独立会员商城 `/membership` 提供始终可发现、可执行的页面退出入口，解决用户进入商城后只能依赖浏览器导航或键盘退出的问题。

## 交互契约

- 页面右上角显示一个固定的 `×` 图标按钮，滚动商城内容时保持可见。
- 按钮的可访问名称为“关闭会员商城”，支持鼠标、触控和键盘操作。
- 当前浏览器历史中存在可返回页面时，点击按钮返回进入会员商城前的页面。
- 没有可返回历史时，点击按钮进入首页 `/`，避免关闭操作无响应。
- 付款弹窗打开时只显示并使用弹窗自身的关闭入口，页面级按钮不参与弹窗关闭。
- 未打开付款弹窗时，`Escape` 与页面按钮复用同一退出逻辑。

## 视觉与响应式

- 使用 Lucide `X` 线性图标和现有语义颜色、表面及焦点 Token。
- 交互热区固定为 44×44px，桌面和移动端均满足触控要求。
- 按钮固定在可视区域右上角，层级低于 Modal、高于商城内容，不遮挡套餐主要操作。
- 支持可见的 `:focus-visible` 状态；不增加装饰性容器、渐变或阴影。

## 实现边界

- 退出目标判断使用单一纯函数，页面按钮和 `Escape` 共用。
- 不改变会员数据加载、套餐选择、订单创建或付款弹窗状态机。
- 不增加浏览器关闭标签页能力；Web 页面只能执行站内导航。

## 验收

- 自动化测试覆盖有历史、无历史、付款弹窗打开和非 `Escape` 按键。
- 页面结构测试覆盖按钮语义、Lucide 图标与样式入口。
- 前端全量测试和生产构建通过。
- 本地 `/membership` 可访问，按钮尺寸、焦点和响应式位置符合设计规范。
