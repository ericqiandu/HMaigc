# 后台音色管理页面统一排版设计

## 业务目标

把 `/admin/voices` 接入已经落地的后台数据页语言，使管理员按“音色概览 → 音色筛选 → 音色目录”的固定顺序维护 MiniMax Speech 音色。改造只调整页面信息层级、共享表面、空状态入口和响应式表现，不改变音色同步、创建、克隆、编辑、删除、发布或权限规则。

## 当前事实

- 页面只读取 `minimax-speech` 类型渠道，并以当前选中渠道为音色目录范围。
- 现有真实能力包括供应商同步、目录音色新增、音色克隆、关键词与类型/状态筛选、分页、编辑、删除和模型兼容范围配置。
- 音色请求具有渠道首次加载、音色首次加载、失败、空渠道、空音色和成功目录等不同状态；这些事实不得合并或伪装。
- 编辑 Drawer 已具备表单校验、脏状态关闭保护、克隆文件边界、授权确认与保存期间防重复提交。

## 采用方案

复用后台现有共享数据布局，不新增音色页面专用卡片体系：

1. **音色目录概览**：使用 `AdminMetricBand` 展示 MiniMax Speech 渠道数、当前渠道音色总数、已发布音色数和需处理音色数。指标全部从已成功读取的渠道和当前音色目录计算；读取失败时不得展示伪造零值。
2. **音色筛选**：使用 `AdminFilterSection` 与现有 `ListToolbar`，依次放置渠道、关键词、类型和状态筛选；结果数量保留在筛选区尾部。
3. **音色目录**：使用 `AdminContentSection` 与 `TableSurface` 承载标题、当前渠道说明、表格、分页、加载、错误和空状态。
4. **页面级操作**：同步供应商、克隆音色和新增目录音色继续位于页面标题区域；没有可用渠道时保持禁用，不制造可执行假象。
5. **空渠道处理**：空状态提供“前往模型中心”明确入口，指向 `/admin/models`，由管理员完成真实渠道、音频模型和价格配置后返回。
6. **编辑流程**：继续使用现有 Drawer、确认弹窗和请求函数，仅对齐共享后台主题与移动端尺寸，不改提交路径。

页面阅读顺序固定为“页面标题与操作 → 音色目录概览 → 音色筛选 → 音色目录”。

## 指标与状态契约

- **MiniMax Speech 渠道**：成功读取的 `minimax-speech` 渠道数量。
- **当前渠道音色**：当前选中渠道成功读取的音色数量。
- **已发布音色**：当前目录中 `enabled === true` 的数量。
- **需处理音色**：当前目录中供应商状态为 `failed`、`uncertain` 或 `missing` 的数量。
- 渠道首次加载失败时，用 `AdminContentError` 代替所有依赖渠道事实的内容，并提供重试。
- 音色首次加载失败时，保留已确认的渠道事实，但音色依赖区域显示明确错误和重试，不把失败投影为零音色。
- 筛选无结果与目录为空继续使用不同文案；刷新失败不得清空上一次成功目录。

## 视觉与响应式规则

- 只使用后台语义 Token、共享数据页组件和既有 Ant Design 控件。
- 页面、区块标题、正文、表格和按钮沿用已统一的后台字体层级。
- 独立区块最多一层可见圆角边界；筛选、表格和分页不形成嵌套卡片。
- 桌面指标横排、筛选紧凑排列；1024px 下允许筛选换行。
- 390px 下筛选单列，页面操作等宽换行且热区不低于 44px；宽表只在内容区内部滚动。
- 日间和夜间保持相同结构、密度与字号，只切换语义表面、边界和文字颜色。

## 保持不变的业务契约

- 不修改 API、DTO、后端、数据库、权限、积分价格或供应商协议。
- 不改变当前渠道选择、筛选、分页、同步、克隆、创建、编辑和删除行为。
- 克隆音频仍限制为 10 秒至 5 分钟、20MB 以内的 MP3、M4A 或 WAV，并继续要求授权确认。
- 密钥与供应商敏感信息不进入页面、测试夹具、日志或错误展示。
- 所有失败继续显式显示，不新增静默回退、默认数据或伪成功状态。

## 实施边界与预算

生产职责不超过三项：

1. 音色页面接入共享数据布局。
2. 真实指标与空渠道操作入口。
3. 音色页响应式样式收敛。

预计修改不超过 4 个生产文件，净新增生产代码不超过 260 行。若实现需要修改后端契约、增加平行状态模型或超出预算 50%，停止实施并重新确认范围。

## 验收标准

- 真实页面按“概览、筛选、目录”顺序展示，且只有一个 `h1`。
- 四项指标与当前成功读取的数据一致；加载失败不会显示伪造零值。
- 同步、克隆、新增、编辑、删除、筛选和分页流程保持可用。
- 空渠道状态可以直接进入模型中心；空音色、筛选空结果和失败状态事实互斥。
- 1440×900、1024×768、390×844 的日间与夜间主题无页面级横向溢出，表格滚动保持局部。
- 定向测试、全量 Web 测试、生产构建和包体预算通过。
- 只重建无状态 Web 容器；本地后端和 `.local/data` 不变。
