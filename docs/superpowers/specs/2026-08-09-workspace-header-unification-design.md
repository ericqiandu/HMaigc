# 工作区页头与首页统一设计

## 背景

首页与普通工作区目前分别维护品牌区、积分入口、会员入口和账户菜单。两套实现已经产生可见漂移：Logo 容器、Logo 图片、站点名称字号、会员图标和账户胶囊的尺寸与样式均不一致。画布编辑器还有第三套顶部栏，但用户明确要求本轮暂不改动画布编辑器。

## 目标

- 普通工作区页头的品牌与账户视觉以首页为唯一基准。
- 首页与工作区复用同一组品牌、会员和账户展示能力，阻止后续样式再次漂移。
- 保留工作区现有浮动导航、页面内容结构、路由行为和数据请求契约。
- 不改动画布编辑器的顶部栏及画布专用操作。

## 非目标

- 不统一 `/canvas/:id` 画布编辑器顶部栏。
- 不改变会员商城、积分超市、登录注册与管理后台的独立信息架构。
- 不修改积分、会员、公告、邀请、账户或主题切换的后端接口和业务逻辑。
- 不新增第二套图标、颜色、间距或响应式标准。

## 路由范围

统一普通工作区路由，包括：

- `/projects` 及项目详情路由
- `/tasks`
- `/assets`
- `/skills`
- `/teams`
- `/wallet`
- `/settings`
- `/canvas` 画布列表

排除：

- `/canvas/:id` 画布编辑器
- `/membership`
- `/credit-store`
- `/login`、`/register`
- `/admin/*`

## 方案选择

采用“共享视觉原语、保留页面壳层”的方案：

1. 抽取共享 `SiteBrandLink`，统一站点 Logo、站点名称、焦点状态与自定义 Logo 尺寸。
2. 抽取共享会员标识组件，复用首页现有金色会员图标，替换工作区当前的 Lucide `Gem`。
3. 工作区直接复用首页账户操作组件，使积分、会员文案、头像、菜单和移动端收缩规则由同一实现负责。
4. `UpdreamHeader` 与 `WorkspaceTopBar` 只负责各自壳层布局；不再分别复制品牌与账户内部结构。
5. `WorkspaceFloatingNavigation` 继续负责工作区路由导航，不并入首页页头。

不采用“只调 CSS”的方案，因为它保留重复 DOM 与图标实现，无法消除后续漂移。也不采用“所有页面直接挂首页完整页头”，因为首页 72px 营销页头会降低工作区内容密度并干扰浮动导航。

## 视觉与交互契约

### 品牌区

- 首页与工作区使用相同的 40px 品牌点击区。
- Logo 标记容器、默认 Logo、自定义 Logo 与站点名称尺寸完全一致。
- 站点名称使用同一字体、字重、字距和截断行为。
- 亮色、暗色、自定义 Logo 与默认 Logo 使用同一主题规则。
- 保留返回首页的链接语义和可见键盘焦点。

### 账户区

- 积分、会员与账户头像形成同一 40px 高账户胶囊。
- 积分使用首页现有图标、格式化规则和实时余额数据。
- 会员入口使用首页现有金色会员图标以及 `useMembershipAction` 返回的真实文案。
- 账户菜单以首页为唯一来源，提供积分中心、会员、邀请、设置、管理员入口、主题切换和退出登录。
- 团队与技能继续由工作区浮动导航承载，不再在账户菜单重复展示；路由与能力均不删除。
- 公告入口与邀请入口保留现有真实功能，不通过复制请求或创建第二套查询状态实现。

### 响应式

- 桌面端保持完整站点名称、积分、会员文案和账户入口。
- 639px 以下保持至少 44px 的主要触控热区，允许隐藏会员文字但保留图标与可访问名称。
- 420px 以下允许隐藏站点名称和次级数字，但不得隐藏返回首页、会员入口或账户入口。
- 不增加页面级横向滚动或依靠裁切掩盖溢出。

## 组件与职责边界

- 共享组件只接收站点设置、账户事实和必要回调，不感知具体业务页面。
- 数据 hooks 保持现有 owner：站点设置、余额、会员状态、用户状态和主题状态不迁移到页面组件。
- 首页与工作区不得各自定义会员 SVG、Logo 尺寸或账户菜单结构。
- 共享组件样式使用 `design-tokens.css` 的语义 Token；不复制首页当前散落的硬编码颜色到新业务样式。
- 本轮不触动画布顶部栏组件或 `canvas-chrome.css`。

## 失败与加载状态

- 用户状态尚未 hydration 时保留明确骨架，不伪造账户信息。
- 余额或会员请求失败继续使用现有 hook 的明确状态与文案，不增加默认数字或假会员状态。
- 自定义 Logo 加载行为沿用站点设置契约，不新增静默替代数据。

## 测试策略

先写失败测试，再实现：

1. 组件测试断言首页和工作区均渲染同一品牌原语及相同 Logo 来源标记。
2. 组件测试断言工作区会员入口使用统一会员图标和真实会员文案，不再渲染 `Gem`。
3. 路由/壳层测试断言普通工作区显示统一页头，`/canvas/:id`、会员商城、积分超市和后台仍按原范围排除。
4. 浏览器回归覆盖 `/`、`/projects`、`/tasks`、`/assets`、`/skills`、`/teams`、`/wallet`、`/settings`、`/canvas`。
5. 在 1440px 与 390px、亮色与暗色下比较 Logo、会员入口、账户区尺寸，并检查横向溢出、可访问名称和触控热区。
6. 运行 Web source tests、TypeScript 检查、生产构建与受影响浏览器门禁。

## 回滚边界

改动仅涉及前端共享页头组件、样式、测试和设计文档，不涉及数据库、接口、权限或业务数据。单一提交即可独立回滚。
