## 历史资源迁移与静态资源 CDN

- 在生产数据副本上执行本地资源迁移，核对图片、视频、音频和文件资源均先上传并通过大小、ETag 校验，再切换 `resources` 引用；原文件仍存在于 `backend-data` 卷。
- 在上传中断、OSS 403/5xx、源文件缺失、源文件大小变化和资源记录并发变更场景下，任务必须保留失败明细且不得切换对应资源。
- 在迁移 Worker 重启后核对 `running` 明细回到待执行状态，确定性对象键不会产生重复业务资源，成功明细不会再次上传。
- 验证只有管理员可以查看、创建和重试迁移任务；开始与重试操作均写入管理员审计，错误确认短语不创建任务。
- 使用独立静态资源 Bucket 和 CDN 域名发布 `v1.0.13`，核对全部构建产物位于 `releases/v1.0.13`，`manifest.json` 可经 CDN 读取且文件具有一年不可变缓存。
- 验证静态资源 Bucket 的 CORS 只允许正式站点 Origin 的 GET/HEAD；JS 模块、CSS、首页视频、图标、MediaPipe WASM 与模型文件均不再从业务服务器下载。
- 回滚到上一版本后核对旧 Web 镜像仍引用旧版本静态目录；新版本目录保留且不覆盖旧对象，CDN 缓存无需清理。
- 模拟任一静态文件上传、HEAD 校验或 CDN 清单读取失败，GitHub Actions 必须在发布 Web 镜像前明确失败。
- 验证删除独占图片、视频、音频和文件素材时同步删除对应 OSS 对象，并把资源记录标记为已删除；资源列表不再返回已删除记录。
- 验证 OSS 403/404/5xx：404 作为幂等删除成功，403/5xx 必须保留素材与资源记录并向用户返回明确错误。
- 验证同一资源被多个素材、个人画布、团队画布、角色版本或音色引用时不会误删；删除最后一个素材引用后才清理对象。
- 验证资源处于历史存储迁移待执行或运行状态时禁止删除，迁移结束后重新删除可正常完成。

## MiniMax Speech 与音色克隆

- 使用真实 MiniMax API Key 验证 `speech-2.8-hd` 与 `speech-2.8-turbo` 非流式合成，确认 MP3、WAV、FLAC 音频可保存到资源存储，任务、积分账单和请求日志保留同一 `trace_id`。
- 验证后台同步系统音色、克隆音色与生成音色可重复执行且不产生重复目录，正确保留供应商返回的多段音色说明，也不会覆盖已配置的会员策略和兼容模型。
- 验证供应商完整目录不再返回的历史 `active` 音色会被标记为 `missing` 并停用；`pending_activation`、`creating`、`uncertain` 不会被同步任务误判为已下架。
- 使用已获得声音本人授权的 10 秒至 5 分钟、20MB 以内 MP3、M4A、WAV 样本分别验证克隆成功与供应商拒绝路径。
- 验证克隆源文件不会落盘，数据库只保存文件名、大小、SHA-256 与授权确认时间；非管理员不能调用同步、克隆、编辑和删除接口。
- 验证同一克隆幂等键重复提交只返回已确认成功的同一记录；网络不确定、失败状态必须阻止直接重试并要求供应商核对。
- 验证克隆音色首次正式合成后由 `pending_activation` 变为供应商可查询的 `active`，并在七天未使用删除规则触发前向运营人员提供明确状态。
- 验证普通音色、会员专属音色和模型兼容范围在画布动态列表与服务端任务校验中一致；绕过前端提交无权限或不兼容音色时不创建计费订单、不冻结积分、不调用供应商。
- 验证 MiniMax `base_resp.status_code` 非零、成功响应缺少音频、`data.status != 2`、文本达到 10000 字符、语速超出 0.5–2.0 和不支持的音频格式均明确失败并可从请求日志定位。
- 验证 MiniMax 渠道无法通过通用系统代理绕过任务队列、积分扣费和音色授权。
- 验证音色选择器可按供应商语言目录筛选，首次试听生成固定短句并写入 `channel_voice_previews`，30 天内重复播放不再次调用供应商；无权限、模型不兼容、供应商失败和缓存摘要损坏均显式失败。
- 验证音色选择窗口在桌面、1024px 与 390px 视口下可用：语言分类、搜索、试听、会员标识和选中状态完整显示，供应商大目录仅虚拟渲染可见行且滚动后结果连续。
- 验证音频模型、停顿、语气词和参数弹层使用统一的节点浮层层级；模型说明与积分价格可读，停顿和语气词仅在用户选择后插入，打开弹层不得修改节点配置。
- 验证音频节点可配置语气、语言增强、语速、音量、音调、格式、采样率、比特率和声道；停顿标签与 `speech-2.8` 语气标签写入实际合成文本，前端保存值、任务请求和供应商请求三者一致。
- 验证 MP3、WAV、FLAC 的参数联动符合 MiniMax 契约：非 MP3 不提交比特率，不支持的采样率、比特率、声道、情绪、语言或越界数值在调用供应商前明确失败。
