## 画布引用、连线与媒体性能

- 在图片和视频节点提示词任意光标位置输入 `@`，确认菜单同时展示当前画布图片、视频、音频和公开 Skills，已连接资源排在前面；选择未连接资源时先创建合法连接再原位插入，连接失败、输入法组合或预览加载失败时不得移动光标、修改正文或提交错误资源。
- 分别通过拖拽、`@` 引用和 Agent `connect_nodes` 尝试 Video → Image、Video → Audio，确认前端与服务端均返回同一明确错误；Image/Audio → Video 保持可用。刷新含历史非法边的旧画布并修改无关节点时不得被阻断，新建或更新该非法边时必须拒绝。
- 在包含大量节点和连线的画布持续拖动单节点与多选节点，确认 pointermove 期间只更新拖动节点和相邻路径，选择态、自动保存及完整连接派生不参与每帧计算；释放后位置只提交一次且撤销可恢复。
- 登录用户分别上传图片、视频和音频，确认上传失败时明确报错且不产生本地影子资源；成功时只写当前素材、建立项目关联并立即显示。刷新页面后图片走受控直达地址，视频/音频支持 Range 播放和 seek，项目查询刷新失败只记录告警而不伪造资产失败。
- 退出登录后以访客模式上传媒体，确认数据只进入当前浏览器本地作用域；重新登录不得把访客资源误归属到账号，也不得跨用户读取资源地址。

## 画布跨浏览器删除

- 浏览器 A 与浏览器 B 登录同一账号并同步同一画布；A 删除后刷新 B，确认 B 的本地缓存被服务端墓碑清除，数据库不再出现同一画布 ID。
- 在 B 完成列表读取后、提交旧本地画布创建前由 A 删除，确认 B 收到 HTTP 410 后只清理该陈旧副本；409、断网和服务端 5xx 必须保留本地画布并显式报错。
- 对个人画布和团队画布分别验证重复删除幂等、当前团队成员可见删除事实、已移除成员与无关账号不可见；强制删除事务失败时画布、分享和墓碑必须全部保持原状。
- 从历史硬删除版本升级后，确认系统不伪造旧墓碑；对已经被旧浏览器复活的画布重新删除一次后，其他客户端不再复活该 ID。

## 单一 Agent Runtime

- 从首页输入不带附件的 Agent 指令并发送，确认立即进入新画布，不再等待账号内其他未同步画布或素材；新画布尚未完成定向远端创建时 Agent 不提前提交，创建完成后再建立 revision/CAS 基线并只执行一次首轮请求。模拟定向创建失败时，画布保留本地内容并显示一次明确错误，重试不得重复创建 Agent run。
- 在画布选择一个已保存渠道模型且提示词明确标记 Skill 的视频节点后打开 Agent，确认输入框默认显示相同模型与 Skill；发送后这些标签从输入区进入用户消息并保持只读，刷新历史仍从服务端冻结配置恢复。再选择模型不同的多个视频节点，确认 Agent 不猜测任一默认模型。
- 在积分充足的真实自动模式画布中仅请求一个 5 秒无声文生视频，选择公开 `supportsTextToVideo=true` 的 Seedance 模型并只批准一次视频报价；核对供应商请求不包含参考图片、媒体 Task/账单各一份、Resource 为 ready video、画布 revision 只增加一次且视频节点可播放。再以不支持文生视频的测试模型验证缺同镜分镜时在报价前返回 `production_prerequisite_missing`，不出现审批、Task、账单或隐式图片任务。
- 在生产升级副本验证第一方技能迁移：首次启动应发布全部内置导演技能，再次启动不得新增版本；手工篡改已发布版本校验值或正文后启动必须整笔失败，不能覆盖历史事实。

- 从已发布短剧总导演与分镜连续性导演历史版本的生产副本升级到 V3，确认旧正文、校验值和历史 run 冻结事实保持不变，新目录与新 run 只引用 V3；重复升级不得创建额外版本或改变目录更新时间。
- 用两个账号分别激活、收藏同一技能，确认目录只从本地数据库读取且状态严格隔离；同一账号依次激活和收藏时两个状态都保留，旧外部技能状态应显式报错并由管理员清理，不能静默隐藏。
- 创建选择第一方导演 Skill 的 Agent run，核对 checkpoint 冻结目录、版本与 64 位 SHA-256 校验值，`skill.load` 加载精确正文；随后发布新版本时历史 run 仍使用原版本，新 run 使用新版本。
- 让 `production.render` 以语义相同但 JSON 键顺序不同的参数连续返回两次完全相同的结构化准备失败，确认第一次只创建一个纠错模型步骤、第二次明确终结 run；若第二次失败原因不同，必须继续同一 Agent 链修正，不能误判为死循环。
- 使用上游测试账单验证媒体与 Token 核对：`billing.status=succeeded` 但 `task_status=failed`、相同任务返回不同 `order_id`、`failed` 账单携带非零金额时均保留冻结积分并进入人工核对，不能结算、退款或覆盖已记录的上游订单事实。
- 在后续 Web 桥接完成后，从个人画布与团队 editor 画布分别批准一次 `canvas.apply_ops`，确认节点修改只增加一个 revision，刷新或重复提交不会产生第二条 CanvasChange；viewer、失效团队和跨画布调用必须显式拒绝。
- 模拟画布已经提交、Runtime 工具结果事务尚未提交时重启进程，确认恢复后沿同一 `clientMutationId` 收敛到原 committed revision；协作者抢先提交导致 revision 过期时，主 Agent 应收到 `canvas_revision_conflict` 并重新读取画布，不覆盖他人修改。
