# Agent 可见消息投影与状态观察

可见文本首批立即持久化，后续 delta 在下次输入且距上次写入达到 200ms 时合并写入；流结束显式 flush 剩余文本。不是独立定时刷新，输入停顿期间可能等待后续输入或结束。只有写入成功才推进本地已持久化文本；失败保留待写内容并返回错误。

模型运行状态每秒观察一次，连续三次读取失败取消请求，流结束后最多再读取三次权威状态。观察失败次数随供应商流式事实记录，不伪造状态或切换模型。供应商/投影错误与取消原因合并保留，不相互覆盖。

该组只涉及文本落库频率、状态观察与诊断，不改变 v10 项目工具、媒体计费或画布协议。测试覆盖批量合并、末尾 flush、失败不推进状态、错误合并和读取失败恢复；真实供应商/浏览器链路仍须另行验收。
