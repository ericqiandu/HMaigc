# Responses 流式文本审查

Responses 解析以 `output_index` 和 `content_index` 保存独立片段，`output_text.done` 仅与对应片段已收到的 delta 比较；重复相同 done 不重复输出，完成后追加或修改均显式失败。提供的 `item_id` 必须保持稳定且不能跨输出项复用。错误只描述协议冲突，不回显正文。

首个位置 `(0,0)` 实时输出，其余位置缓存到 completed，按输出/内容索引顺序拼接；因此交错片段不会倒序插入已显示文本。completed 提供 output 时，逐片段核对存在性、身份和正文前缀，已经 done 的片段必须完全相等；不允许仅凭总文本相等掩盖边界冲突。后续片段展示延迟是保证只追加显示的明确取舍。

回归覆盖顺序/交错多片段、不同输出项、重复 done、身份与生命周期冲突、快照片段边界冲突、完成文本补齐、失败与截断。该协议解析修复不改变模型选择、计费或 Agent 项目工具契约，不等于真实供应商与浏览器全流程已经验收。
